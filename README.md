# Система учёта расходов

Консольное приложение для регистрации личных расходов и контроля денег на
счетах. Тема №14 индивидуального проекта.

## Основные сущности

| Сущность | Назначение |
| --- | --- |
| Пользователь | Владелец счетов и расходных операций |
| Счёт | Место хранения денег с текущим балансом |
| Категория | Назначение расхода: продукты, транспорт, учёба и т. п. |
| Операция | Расход со счёта пользователя в выбранной категории |

## Возможности

- добавление пользователей, счетов и категорий;
- регистрация расходной операции;
- проверка принадлежности счёта пользователю;
- запрет расхода при недостаточном балансе;
- просмотр данных и расчёт расходов за месяц;
- хранение данных в JSON-файлах.

## Развитие проекта

- ПР1: начальный сценарий расчёта расхода;
- ПР2: коллекции, функции, циклы, модули, исключения, JSON и тесты;
- ПР3: классы `User`, `Account`, `Category`, `Operation`, объекты и их
  взаимодействие.

## Установка и запуск

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

## Проверка

```powershell
.\.venv\Scripts\python.exe -m pytest -v
.\.venv\Scripts\python.exe -m flake8
```

Данные создаются в каталоге `data` после первого изменения.
