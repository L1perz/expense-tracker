# Система учёта расходов

Приложение для регистрации личных расходов и контроля денег на
счетах. Тема №14 индивидуального проекта.

## Основные сущности

| Сущность | Назначение |
| --- | --- |
| Пользователь | Владелец счетов и расходных операций |
| Счёт | Место хранения денег с текущим балансом |
| Категория | Назначение расхода: продукты, транспорт, учёба и т. п. |
| Операция | Расход со счёта пользователя в выбранной категории |

## Возможности

- добавление пользователей, счетов и категорий;
- регистрация расходной операции;
- проверка принадлежности счёта пользователю;
- запрет расхода при недостаточном балансе;
- просмотр данных и расчёт расходов за месяц;
- хранение данных в JSON-файлах.

## Развитие проекта

- ПР1: начальный сценарий расчёта расхода;
- ПР2: коллекции, функции, циклы, модули, исключения, JSON и тесты;
- ПР3: классы `User`, `Account`, `Category`, `Operation`, объекты и их
  взаимодействие.
- ПР5: Django 5.2, приложения `homepage`, `accounts`, `operations`, маршруты,
  списки и карточки объектов, Bootstrap, собственная ошибка 404.
- ПР6: общий шаблон `templates/base.html`, наследование и включаемые
  фрагменты навигации, счетов и операций; CSS, SVG-логотип и JavaScript;
  контекст, фильтры `date`, `default`, `length` и собственный `money`;
  страницы пользователей и категорий, адаптивное оформление.

Объектная модель находится в `models/`. Счёт ссылается на объект
пользователя, операция — на объекты пользователя, счёта и категории.
Метод `Account.withdraw()` проверяет остаток и списывает расход.
Функции обработки коллекций сохранены отдельно от методов объектов.
`storage.load_project()` восстанавливает связи из JSON без повторного списания.
Денежные значения хранятся целыми копейками, даты — в ISO-формате.

## Установка и запуск

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

## Проверка

```powershell
.\.venv\Scripts\python.exe -m pytest -v
.\.venv\Scripts\python.exe -m flake8
```

Данные создаются в каталоге `data` после первого изменения.

## Веб-приложение

```powershell
.\.venv\Scripts\python.exe manage.py check
.\.venv\Scripts\python.exe manage.py runserver
```

Страницы: `/`, `/accounts/`, `/accounts/1/`, `/operations/`, `/operations/1/`.
В `data/` включены вымышленные демонстрационные данные. Балансы являются
текущими: при чтении исторических операций расходы повторно не списываются.
